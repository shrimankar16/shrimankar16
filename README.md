## 🚀 Featured Projects

### 1. AI Shopify Theme Builder

An AI-powered application that generates Shopify storefront concepts from natural-language prompts, enables real-time previews and inline section editing, and exports Shopify-friendly theme assets.

**Tech stack:** Next.js · React · TypeScript · Tailwind CSS · Node.js

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge&logo=github)](https://github.com/shrimankar16/Shopify-Theme-Builder)

### 2. Split & Settle

A full-stack expense-splitting application for groups sharing travel, rent, and other expenses. It tracks shared costs and calculates optimized settlements using a debt-minimization algorithm.

**Tech stack:** React · Node.js · Express.js · MongoDB · PostgreSQL

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge&logo=github)](https://github.com/shrimankar16/Split-Settle)

### 3. Multi-Agent Travelling Assistant

An AI-powered travel planner coordinating five specialized agents for destinations, flights, hotels, transport, and activities. Includes browser automation, live web research, budget tracking, and persistent state.

**Tech stack:** Python · OpenAI Agents SDK · LangGraph · Stagehand · Supabase · Firecrawl · Tavily API

### 4. AI Quiz Engine

A full-stack AI examination platform featuring AI-generated questions, automatic grading of short answers, role-based access for teachers and students, and RAG-powered personalized practice recommendations.

Includes PostgreSQL pgvector semantic search, automated testing, CI/CD, and real-time features.

**Tech stack:** PHP 8.3 · Laravel 12 · Livewire 4 · PostgreSQL · pgvector · Laravel Reverb · Pest · GitHub Actions
